CAJ 转 PDF（给完全不熟悉电脑的人看）

这是什么？
  知网下载的论文经常是 CAJ 文件，普通阅读器打不开。
  这个小工具能把它变成谁都能打开的 PDF。

Windows 第一次怎么用？
  1. 先安装 Python：打开 python.org，下载 Windows 安装包
  2. 安装时务必勾选 Add python.exe to PATH
  3. 解压本工具，双击「开始转换.bat」
  4. 第一次会弹出黑窗口，等它自己安装，不要关
  5. 在窗口里点「选择文件」，再点「开始转换」
  6. PDF 就在原来那个 CAJ 文件旁边
  7. 如果已经是图片版 PDF，点「识别图片 PDF」

macOS 第一次怎么用？
  1. 双击「开始转换.command」
  2. 如果电脑说无法打开，请右键它，选「打开」
  3. 点「选择文件」，再点「开始转换」
  4. 如果已经是图片版 PDF，点「识别图片 PDF」

Linux 第一次怎么用？
  1. 运行 ./install-desktop.sh（或让会电脑的人帮你运行）
  2. 双击桌面上的「CAJ转PDF」
  3. 如果电脑说「未信任」或「不允许启动」，请右键这个图标，选「允许启动」
  4. 把 CAJ 文件拖进窗口，或点「选择文件」
  5. 点「开始转换」
  6. 如果文件已经是图片版 PDF，点「识别图片 PDF」

还可以这样（Linux）：
  在文件窗口里选中 CAJ 文件，右键 -> 脚本 -> 转成 PDF

注意：
  - 原来的 CAJ 文件不会被删除
  - 如果已经有同名 PDF，会被这次转换覆盖
  - 极少数文件可能转失败。失败时窗口会用人话说明
  - 如果是扫描件，会自动识别上面的中文，识别后可以搜索、复制（可能有个别错字）
  - 已经是 PDF 的扫描件：点「识别图片 PDF」，会另存为「原名-已识别.pdf」，原来的 PDF 不会改
  - 如果打开 PDF 看到的就是乱码（很多 / $ #），说明文字提取已经失败，识别也救不回来，请用原始 CAJ 重新转
  - 识别每一页大约需要几秒钟，页数多时请耐心等待
  - 含很多扫描图片的文件，第一次可能还需要安装免费的 C++ 编译工具
